# 연구하는 교사되기 2027 · 연수 운영 사이트

주소: https://snu27.dumokquoka.com

연수생이 스스로 하고, PM은 시트만 보는 구조예요.

| 연수생 (웹) | PM (구글 시트 "연수운영" 메뉴) |
|---|---|
| 연수 안내 · 일정(요일 자동) · 접속 안내 | ① 오늘 할 일 (미처리 신청, 이수정보 입력 현황) |
| 공지사항 · FAQ | 이수정보 미입력자 목록 + 문자용 번호 한 줄 |
| 셀프 신청 (기수변경 · 수강취소 · 현금영수증 수정 · 기타) | 이수생관리부(연수원 양식 열 순서) 만들기 |
| 이수정보 입력 (시도청 17개, 생년월일·휴대폰·학교명 자동 검사, 재제출=수정) | 강사 위촉공문 자료 (날짜→요일 자동) |
| 내 현황 조회 (+ 납입확인서 인쇄/PDF) | 요일 다시 계산 |

- 디자인 기준: [DESIGN.md](DESIGN.md)
- 연수생 개인정보는 코드에 없고, 전부 구글 시트에만 저장돼요.
- 강사 주민번호·계좌는 이 시트에 넣지 않아요. (별도 시트)

## 처음 한 번 설정 (약 10분)

1. **구글 시트 새로 만들기** → 이름 예: `연구하는교사되기2027_운영DB` (공유하지 말고 나만 보기)
2. 시트 메뉴 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣고 저장
3. 위쪽 함수 목록에서 `setup` 선택 → **실행** → 권한 허용 → 시트 탭들이 자동으로 생겨요
4. **설정** 탭에서 연수명·기수목록·마감일·문의메일·연수비를 채우기
5. Apps Script에서 **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 나오는 **웹 앱 URL** 복사
6. 이 레포의 [`config.js`](config.js) 에 `API_URL: '복사한 URL'` 붙여넣기 → 커밋하면 사이트가 실제 시트와 연결돼요

> 코드를 고친 뒤에는 **배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요. (URL은 그대로)

## 운영 흐름

| 할 일 | 어디서 |
|---|---|
| 연수원 신청자 명단 받기 | `신청자` 탭에 붙여넣기 (기수·성명·휴대폰·이메일·입금액·입금일·상태) |
| 공지 · FAQ 쓰기 | `공지` · `FAQ` 탭에 한 줄 추가 → 사이트에 바로 반영 |
| 연수 시간표 | `연수일정` 탭 (날짜만 넣으면 요일 자동) |
| 셀프 신청 처리 | `셀프신청` 탭 J열을 `완료`로 바꾸고 K열에 한 줄 메모 → 연수생이 내 현황에서 확인 |
| 이수정보 마감 전 독촉 | 메뉴 → 미입력자 목록 → F2 번호 줄을 문자나라에 붙여넣기 |
| 연수원에 이수생관리부 보내기 | 메뉴 → 이수생관리부 만들기 → 엑셀로 다운로드 → 표준양식에 붙여넣기 |
| 강사 위촉공문 자료 | `강사일정` 탭 입력 → 메뉴 → 위촉공문 자료 만들기 |
| 납입확인서 셀프 출력 켜기 | `설정` 탭 `납입확인서_사용` = Y (입금일이 있는 신청자만 출력돼요) |

## 확인이 필요한 부분

- **이수생관리부 열 순서**: 연수원 표준양식(서식 변경 금지) 열 순서와 똑같이 `설정 > 이수생관리부_열순서`를 맞춰 주세요.
- **나이스 개인번호 형식**: 지금은 영문·숫자 5~15자로 느슨하게 검사해요. 정확한 형식을 확인해서 `설정 > 나이스번호형식`(정규식)을 좁히면 오류가 더 줄어요. (사이트 쪽 검사도 함께 수정: `assets/app.js`)
- **납입확인서 발급 주체**: 연수원 또는 운영사 명의 증명서가 따로 필요하면, 셀프 출력은 끄고 공식 양식으로 바꿔야 해요.

## 미리보기

`config.js`의 `API_URL`이 비어 있으면 예시 데이터로 열리는 미리보기 모드예요. 로컬에서는 `python3 -m http.server` 후 `http://localhost:8000` 접속.
