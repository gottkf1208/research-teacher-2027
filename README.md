# 연구하는 교사되기 2027 · 연수 운영 사이트

- 연수생 사이트: https://snu27.dumokquoka.com (GitHub Pages)
- 운영자 관리 페이지: 구글 로그인, 운영자 계정만 (Apps Script 웹앱)
- 데이터: 운영자 구글 시트 1개 + 강사 민감정보용 비공개 시트 1개 (자동 생성)

## 처음 한 번 설정 (10분)

1. 구글 시트를 새로 만든다. 이름: `연구하는교사되기2027_운영DB` (공유하지 않기)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 연다.
3. `Code.gs`에 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여넣는다.
4. 왼쪽 **파일 + → HTML** 로 `Admin` 파일을 만들고 [`apps-script/Admin.html`](apps-script/Admin.html) 내용을 붙여넣는다. 저장.
5. 위쪽에서 `setup` 함수를 고르고 **실행** → 권한 허용. 시트 탭이 자동으로 생긴다.
6. **배포 → 새 배포 → 웹 앱**을 두 번 만든다.
   - ① 공개용: 실행 = 나, 액세스 = **모든 사용자**
   - ② 운영자용: 실행 = 나, 액세스 = **나만**
7. 두 URL을 Claude에게 보낸다. (사이트 연결은 Claude가 함)

운영자 페이지 주소 = ② URL 뒤에 `?page=admin`

> 코드를 바꾼 뒤에는 **배포 관리 → 연필 → 버전: 새 버전**으로 ①② 둘 다 다시 배포 (URL은 그대로).

## 운영자 페이지에서 하는 일

| 메뉴 | 하는 일 |
|---|---|
| 대시보드 | 신청자 수, 처리 안 된 셀프신청, 이수정보 확인 필요 인원 |
| 신청자 명단 | 연수원 신청자 목록을 엑셀에서 제목줄째 복사 → 붙여넣기 → 가져오기. 검색·수정·추가 |
| 셀프신청 처리 | 완료/반려 버튼. 취소·현금영수증은 신청자 명단에 자동 반영 (2027은 기수 변경 접수 안 받음) |
| 이수정보 점검 | NEIS(영문1+숫자9)·생년월일·소속교육청·학교명·중복 검사 → 문자 발송으로 연결 |
| 출결 · 이수 판정 | 연수생이 사이트에서 누른 출석체크→퇴실체크로 날짜별 자동 집계. 미입실·미퇴실 → 문자, 칸 눌러 인정시간 조정, 이수 판정을 신청자 명단 이수(Y/N)에 반영. Zoom 참가자 목록 대조는 보조 |
| 게시판 | Q&A·환불 요청. 내용은 작성자(이름+휴대폰)만 열람. 환불 단계: 접수→검토 중→연수원 전달→환불 완료/반려, 단계별 안내 문자 자동 문구 |
| 문자 발송 | 문자 종류 고르기 → 기수·대상 고르기 → 문구 복사+문자나라 열기 → 번호 복사 → 보냄 기록 |
| 이수생관리부 | 연수원 표준양식(이수정보확인서·이수대장) 열 순서 그대로. 복사 → 양식에 값만 붙여넣기 |
| 공지·FAQ·연수 일정 | 쓰면 연수생 사이트에 바로 반영 |
| 강사 일정 / 강사 정보 / 위촉공문 자료 | 일정은 단일 원본(요일 자동). 주민번호·계좌는 별도 비공개 시트 |
| 설정 | 마감일, 줌·오픈카톡 링크, 연수기간, 이수대장 코드 |

## 동명이인

출석·조회·게시판·이수 매칭·문자 대상은 모두 **이름+휴대폰**으로 묶는다. 이름만으로 매칭하는 곳은 없다. 운영자 화면에는 이름 옆에 `동명이인` 표시가 붙는다.

## 기수 변경

2027은 기수 변경을 받지 않는다. 셀프 신청에서 항목을 뺐고, 서버도 거절한다. 이수정보에서 다른 기수를 골라도 신청자 명단의 기수가 원본이다.

## 보안

- 공개용 배포는 연수생 사이트가 쓰는 3가지(공지/FAQ/일정 읽기, 신청·이수정보 제출, 본인 현황 조회)만 응답한다.
- 운영자 기능은 `isAdmin_()`이 로그인한 구글 계정을 확인한다. 공개용 주소로 `?page=admin`을 열어도 막힌다.
- 강사 주민번호·계좌는 운영 시트가 아닌 별도 파일(`연구하는교사되기2027_강사정보(비공개)`)에 저장된다.
- 이 레포에는 개인정보가 없다.

## 개발 메모

- `index.html` + `assets/` : 연수생 사이트. `config.js`가 비어 있으면 예시 데이터 미리보기.
- `apps-script/Admin.html` : 운영자 페이지 한 파일. 구글 밖에서 열면 예시 데이터로 보인다.
- 디자인 기준: [DESIGN.md](DESIGN.md). 문자 화면은 JVI 선물문자 형식과 쿼카 아이콘.
